03

Why build
another tool?

01

Hardware costs money.

A real MPC, turntables, a mixer and a rack of samplers add up quickly. Importing gear into Southern Africa adds another layer of cost and friction.

02

One workflow beats a giant menu.

If you want to chop a break or practise scratching, you shouldn't have to navigate a production suite designed for every possible use case.

03

Trying it should cost nothing.

The products are free during this early testing phase, for personal or commercial use. The goal is to get real producers using the software and finding the rough edges.

04

Support should be close to the code.

Bug reports go back to the people building the software, so feedback can become a fix instead of disappearing into a ticket queue.

05

Serious audio software can be built here.

EdensFrequency is part of a broader effort to make the software layer of African music technology more visible, capable and locally owned.

04

Ready to make
something?

Windows builds are available now. macOS is planned. Use the installer for the easy path or grab the release archive if you prefer to place the plugin yourself.
