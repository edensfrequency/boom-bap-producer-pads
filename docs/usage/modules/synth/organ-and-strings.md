# Organ and String Machine

Choose **SYNTH > Instrument > Organ** or **String Machine**. Both are built-in
original modelled voices; no sample files are needed. Play MIDI channel 5,
the SYNTH keyboard or the SYNTH part. Both cover A0-C8 (MIDI 21-108).

## Organ

The nine vertical drawbars set partial levels from 0 to 8. Footage labels
identify their registers: 16 ft adds a sub-octave, 8 ft follows the played note,
and shorter footages add higher partials. Changes affect held notes smoothly.
The organ treats velocity as a key switch, so striking harder does not make
it louder; use the SYNTH mixer for level.

**Rotary** sets the stereo effect depth. **Speed** sets its target rate from
0.1 to 8 Hz; the motor changes speed gradually. The effect combines stereo
level and pitch motion. This is an original organ/rotary design; percussion,
key-click and additional cabinet controls are not included.

## String Machine

- **Attack** sets the swell time of new notes, from 0.005 to 2 seconds.
- **Release** sets the damping time chosen at note-off, from 0.03 to 4 seconds.
- **Tone** changes brightness as you play.
- **Ensemble** adds stereo modulation from the three-tap ensemble.

Velocity gently changes level. The voice uses detuned electronic oscillators;
it is a string-machine sound rather than recorded orchestral strings.

## Mixer, projects and export

Both sources use the **SYNTH mixer strip** for volume, pan, mute/solo, sends
and strip processing. Master pitch applies. Sustain pedal and a +/-2-semitone
pitch wheel are supported; A4 is fixed at 440 Hz. Synth MPE, tuning and
modulation controls do not apply to these sources.

Source choice and each model's settings save with your project. Switching
among Synth, Samples, Electric Piano, Organ and String Machine clears held
notes/effect tails while retaining the inactive models' settings. Choosing a
Synth preset selects Synth again. Existing sample-library paths stay in place.

The **SYNTH part's WAV export** uses the selected model through an independent
voice/effect engine. New model controls are project settings, not new DAW
automation parameters or Synth sound-preset/A-B data. Synth-only sound exports
are hidden; use part WAV export to render a phrase.
