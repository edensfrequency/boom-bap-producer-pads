# LOOPS tab: Tape Loops

**In one line:** four loop tracks that play beside your pads, locked to the beat like a tape machine.

## What this part of the plugin is for

Sometimes a beat starts from a bed: a dusty chord loop, a texture, a
crackling break. Tape Loops gives you four of them at once. Load a loop
on each track, press PLAY, and chop and play your pads over the top.
