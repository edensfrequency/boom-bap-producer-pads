# The toolbar: presets, transport and tools

**In one line:** the two rows along the top that stay visible on every tab.

## What this part of the plugin is for

The toolbar holds everything that isn't tied to one tab. That means saving
and loading **presets** (your whole setup under a name, samples included), the
buttons that switch tabs, play/stop, undo/redo, the metronome and tempo when
running without a DAW, the master effects, the safety limiter, and a
**Panic** button that silences everything. The banner above it has
one-click window sizes.

## Questions this answers

- *How do I save my whole beat to use in another project?* Type a preset name and click **Save**. The samples get copied with it.
- *Something is stuck playing!* Hit **Panic**.
- *I made a mistake.* Use **Undo** (Ctrl+Z); **History** shows what each undo step is.
- *The window is too big or small.* Use **Smaller / Mid / Full Screen** in the banner, or drag the window edge.
- *How do I record what the plugin plays as MIDI in my DAW?* Use **MIDI Out**; the guide shows the one-time setup.
