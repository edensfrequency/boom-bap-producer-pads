# PERFORM tab: macros and an XY pad

**In one line:** four big knobs that each move up to eight controls at once, and a pad to play two of them with one finger.

## What this part of the plugin is for

Building a beat means many small knobs; playing it live wants a few big
ones. A macro gathers several controls -- the filter on three pads, the
reverb send, the bass volume -- under one knob, so one move does them all.
The XY pad plays two macros at once: drag across for Macro 1, up for
Macro 2.

## Questions this answers

- *How do I put a knob on a macro?* Turn on that macro's **Assign**, then right-click the knob and pick **MIDI Learn**.
- *Why doesn't my sound jump when I start turning a macro?* Each control moves from where it was when you assigned it toward its far end.
- *Can my DAW automate it?* Yes: the macros are the **Macro 1-4** parameters.
